# NormalTreeCapitator 1.0.4

Changelog since **1.0.3**.

---

## Highlights

- `/tc status` and `/tc status <player>` — view tree capitator toggle state (online or offline)
- Permission hierarchy: `normaltreecapitator.user` and `normaltreecapitator.admin.*` sub-nodes
- Optional `permission` on **groups** and **block-damages** sections (VIP tiers, etc.)

---

## Commands

### `/tc status`

Shows whether tree capitator is currently **enabled** or **disabled** for you.

| | |
|--|--|
| **Permission** | `normaltreecapitator.admin.status` (included with `normaltreecapitator.admin` / `*`) |
| **Usage** | `/tc status` |
| **Console** | Must use `/tc status <player>` |

### `/tc status <player>`

Shows that player's toggle state. Works for **online and offline** players who have joined before.

| | |
|--|--|
| **Permission** | `normaltreecapitator.admin.status` |
| **Usage** | `/tc status Steve` |
| **Tab complete** | Online players, plus offline names (capped) |

**Example output**

```
Tree Capitator is currently enabled for Steve (online).
```

## Permission hierarchy

| Permission | Default | Notes |
|------------|---------|--------|
| `normaltreecapitator.*` | op | Everything |
| `normaltreecapitator.user` | `true` | Basic pack: `use`, `toggle`, `help` |
| `normaltreecapitator.admin` | op | Admin pack + protected saplings + update alerts |
| `normaltreecapitator.admin.status` | op | `/tc status` |
| `normaltreecapitator.admin.reload` | op | `/tc reload` |
| `normaltreecapitator.admin.toggle.others` | op | `/tc toggle <player>` |

Giving `normaltreecapitator.admin` grants every `admin.*` child. Giving `normaltreecapitator.user` grants every basic player permission.

## Config permissions (groups & damage)

Optional `permission` field on a section:

```yaml
block-damages:
  logs:
    damage: 2
    blocks: [minecraft:oak_log]
  logsvip:
    permission: vip   # → normaltreecapitator.damage.vip
    damage: 1
    blocks: [minecraft:oak_log]

groups:
  Trees:
    blocks: [...]
    tools: [...]
  Othervip:
    permission: vip   # → normaltreecapitator.group.vip
    blocks: [...]
    tools: [...]
```

| Kind | Node |
|------|------|
| Group | `normaltreecapitator.group.<value>` |
| Damage | `normaltreecapitator.damage.<value>` |

- Omit `permission` → available to everyone (who can use tree cap).
- A value containing `.` is treated as a **full** permission node.
- **Groups:** gated groups the player qualifies for are preferred over open groups.
- **Damage:** gated rules override open rules for the same blocks when the player has the permission (e.g. VIP pays 1 instead of 2).

## Upgrade notes

1. Drop `NormalTreeCapitator-1.0.4.jar` into `plugins/` and **restart** (new permission nodes).
2. Update LuckPerms / permission plugins:

| Old (1.0.3) | New (1.0.4) |
|-------------|-------------|
| `normaltreecapitator.reload` | `normaltreecapitator.admin.reload` |
| `normaltreecapitator.status` | `normaltreecapitator.admin.status` |
| `normaltreecapitator.toggle.others` | `normaltreecapitator.admin.toggle.others` |

Or grant `normaltreecapitator.admin` / `normaltreecapitator.user`.

3. Run `/tc reload` to merge new message keys into an existing `messages.yml`.
4. Publish jar to Modrinth, then set the Pastebin feed to:

```text
v1.0.4|https://modrinth.com/plugin/normal-tree-capitator/versions
```
