# NormalTreeCapitator 1.0.5

Changelog since **1.0.4**.

---

## Highlights

- Smarter update checker: Pastebin is polled every **30 minutes**; staff are notified when the feed changes, on join, and every **3 hours** while still outdated
- **Structure protection** — tree capitator only runs on chains that look like natural trees (grounded stump + real foliage/canopy); builds and world structures fall back to a normal single-block break
- **Structure cleanup** — orphan leaf-only or log-only leftovers can still be tree-capped when protection is on
- **Player opt-out** — `/tc structure-protection` for players with that permission (not in the default `user` pack)
- **Partial durability cuts** — when `break-tool: false` and the axe cannot afford every trunk, 0-cost leaves stay put so you never strip a canopy off leftover logs
- **Command UX** — `/tc` shows your toggle state; `/tc <player>` for staff; `/tc status` shows live chain break progress + ETA; `/tc help` lists only commands you can use
- **User pack permissions** — every default-player command has its own node under `normaltreecapitator.user`
- **`/tc version`** — admin-only (`normaltreecapitator.version`, default op; included in `admin` pack)
- **Languages** — chat strings live in `languages/` (`EN-us`, `EN-gb`, `EN-sg`, `DE-de`, `ES-es`, `PT-br`); server default via `language:` / `/tc language server`; optional personal `/tc language` (`normaltreecapitator.language`, not in `user`)
- **`admin.state`** — staff `/tc <player>` permission renamed from `admin.status`

## Update checks

The plugin reads the latest release from [Pastebin raw](https://pastebin.com/raw/nc6CbGem) (`version|download url`).

| When | What happens |
|------|----------------|
| **Every 30 minutes** | Re-fetches Pastebin. If a newer version appears (or the feed changed), console + online ops / `normaltreecapitator.admin` are notified |
| **Plugin enable** | Immediate Pastebin check; notify console + online staff if outdated |
| **Player join** | Fresh Pastebin check for that player if they are op or have `normaltreecapitator.admin` |
| **Every 3 hours** | Reminder to console + online staff while still outdated |
| **`/tc version`** | Fresh check for staff/ops who run it (clickable link if outdated) |

The 30-minute poll does not spam the same version repeatedly — it announces when the remote version/URL changes (or that version has not been announced yet). The 3-hour job is the recurring reminder.

## Structure protection

Enabled by default via `settings.structure-protection: true`.

Instead of scanning for “structure blocks” next to logs, the plugin asks whether the chain looks like a **natural tree**. If it does not, tree cap is skipped and vanilla single-block break proceeds.

| Check | Passes when | Catches |
|-------|-------------|---------|
| Foliage present | Chain has leaves / wart / mushroom blocks (skipped if `max-chain` capped) | Log walls / cabins |
| Natural leaves | If overworld leaves exist, most must be non-persistent | Player-placed leaf decor |
| Grounded stump | At least one lowest trunk column sits on natural/plantable ground | Floating log platforms |
| Canopy | Some foliage above the lowest trunk (skipped if capped) | Flat log floors with no crown |

Real trees next to houses still tree-cap. No material allow/deny lists to maintain.

### Orphan cleanup (`structure-cleanup`)

When structure protection would block a chain, cleanup can still allow:

| Chain | Allowed when |
|-------|----------------|
| **Leaf-only** | Connected foliage with no trunks (leftover canopy) |
| **Log-only** | Connected trunks with no foliage, grounded, and only touching air / other logs in the chain / the floor beneath them |

### Config

```yaml
settings:
  structure-protection: true
  structure-cleanup: true
```

| Key | Default | Notes |
|-----|---------|--------|
| `structure-protection` | `true` | Master toggle |
| `structure-cleanup` | `true` | Allow orphan leaf-only / log-only cleanup while protection is on |

### Player command

Not in `normaltreecapitator.user`. Grant separately (or via `normaltreecapitator.*`). If server `structure-protection` is `false`, the command reports disabled.

| Command | Permission | Default | Effect |
|---------|------------|---------|--------|
| `/tc structure-protection` | `normaltreecapitator.structure-protection` | `false` | Toggle whether structure protection applies to you |

Saved in `playerdata/<uuid>.yml` as `structure-protection`.

### Message

| Key | Default |
|-----|---------|
| `structure-protected` | `&cTree capitator won't break structures. Break blocks normally.` |

Set the message to empty to silence it. Debug (`settings.debug: true`) logs reasons such as `no-foliage`, `foliage-only`, `persistent-leaves`, `not-grounded`, `no-canopy`.

## Commands (1.0.5)

### Default user pack (`normaltreecapitator.user`)

Each command/feature has its **own** permission node. Granting `normaltreecapitator.user` enables all of them.

| Command / feature | Permission | Default | Effect |
|-------------------|------------|---------|--------|
| (breaking) | `normaltreecapitator.use` | `true` | Tree cap when breaking blocks |
| `/tc` | `normaltreecapitator.status` | `true` | Your toggle state |
| `/tc status` | `normaltreecapitator.progress` | `true` | Live break progress (`done/total`, `%`, rough ETA) |
| `/tc help` | `normaltreecapitator.help` | `true` | Only the subcommands you can use |
| `/tc toggle` | `normaltreecapitator.toggle` | `true` | Toggle tree capitator for yourself |

### Other commands

| Command | Permission | Default | Effect |
|---------|------------|---------|--------|
| `/tc <player>` | `normaltreecapitator.admin.state` | op | Another player's toggle state (online or offline) |
| `/tc toggle <player>` | `normaltreecapitator.admin.toggle.others` | op | Toggle for another online player |
| `/tc reload` | `normaltreecapitator.admin.reload` | op | Reload configs |
| `/tc version` | `normaltreecapitator.version` | op | Installed version (+ update link if outdated) |
| `/tc language <code>` | `normaltreecapitator.language` | `false` | Personal chat language (not in `user`; saved in playerdata) |
| `/tc language server <code>` | `normaltreecapitator.admin.language` | op | Server default chat language (`language:` in config.yml) |
| `/tc structure-protection` | `normaltreecapitator.structure-protection` | `false` | Opt out of structure protection (not in `user`) |

## Upgrade notes

1. Drop `NormalTreeCapitator-1.0.5.jar` into `plugins/` and **restart**.
2. Run `/tc reload` to merge new `config.yml` / `languages/*.yml` keys into existing files.
3. Remove any old `structure-blocks` / `structure-ignore` keys if present — they are unused.
4. Set `structure-protection: false` if you want the old behavior (tree cap on any connected wood).
5. Grant `normaltreecapitator.structure-protection` only to players who should be able to opt out.
6. Rename LuckPerms node if needed: `normaltreecapitator.admin.status` → `normaltreecapitator.admin.state` (or grant `normaltreecapitator.admin`).
7. `/tc version` is admin-only now (`normaltreecapitator.version` defaults to op, included in `normaltreecapitator.admin`). Remove it from player groups if you had granted `user` and expected players to see it.
8. Chat messages live in `languages/` — server default via `language:` in `config.yml` or `/tc language server <code>`. Grant `normaltreecapitator.language` for personal `/tc language <code>` (not in `user`). An old root `messages.yml` is migrated to `languages/EN-us.yml` once if needed.
9. When publishing, update the Pastebin version feed to:

```text
v1.0.5|https://modrinth.com/plugin/normal-tree-capitator/versions
```
