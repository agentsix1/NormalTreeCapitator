# NormalTreeCapitator Update — Changelog
Tree capitator logic has been brought in line with **Normal Essentials**. Drill and veinminer features were **not** included (standalone tree cap only).
---
## Behavior Fixes & Improvements
### Sneak behavior
- **Fixed sneak gate logic** — previously only blocked when `must-sneak: true` and the player was not sneaking
- **`must-sneak: true`** — tree cap only while sneaking
- **`must-sneak: false`** — tree cap only while standing; sneaking uses vanilla single-block break
- **Reliable sneak detection** — tracks shift via toggle/join/quit events so break-time sneak state is accurate on Paper/Folia
### Tree breaking
- **Single-block trees now work** — removed the old abort when the chain had only one block
- **Trunk-first break order** — logs, wood, and stems break before leaves so durability and `max-chain` are not consumed by canopy first
- **Folia-safe flood fill** — region-safe chunk reads; avoids cross-region sync loads
- **Cooldown between caps** — configurable delay between tree-cap activations
- **Processing messages** — “Processing tree breaks… please wait.” on all chains (sync and async), with a done message when finished
### Replant
- **Deferred replant** — full tree breaks first, then stumps are replanted from actually broken logs
- **Per-species saplings** — correct sapling, fungus, or propagule per log type
- **2×2 stump support** — dark oak and multi-column bases replant all corners when sibling columns were broken
- **Invincible replant** — unchanged; admins with permission can break protected saplings
### Tools & drops
- **Tool durability budgeting** — when `break-tool: false`, chains are capped so the axe keeps at least 1 durability
- **Per-block durability costs** — leaves/wart/shroomlight can cost 0; logs cost 1 (configurable)
- **Merge vs per-block drops** — merge all drops at origin, or drop at each block as it breaks
### Compatibility & diagnostics
- **Protection plugin support** — each chain block fires a synthetic break event (WorldGuard, GriefPrevention, Lands, CoreProtect, etc.)
- **Debug logging** — optional `[TreeCap]` console lines for sneak checks, chain start, per-block breaks, replant attempts, and skips

## New Config Options
| Setting | Description |
|--------|-------------|
| `merge-item-drops` | Merge all drops at origin (`true`) or drop per block (`false`) |
| `cooldown-ticks` | Ticks between tree-cap activations |
| `replant-consume-saplings` | Consume saplings from tree drops (`true`) or replant for free (`false`) |
| `debug` | Enable verbose `[TreeCap]` logging |
| `async-delay` | Ticks between async break waves |
| `block-damages` | Per-material durability cost groups (e.g. `logs`, `leaves`) |
### Default changes (embedded config)
| Setting | Old default | New default |
|--------|-------------|-------------|
| `break-tool` | `true` | `false` |
| `replant` | `false` | `true` |
> **Note:** Existing server configs keep their current values until you edit them. Only new/missing keys pick up embedded defaults on load.

## Code Changes
### New classes
- `TreeReplant` — deferred replant system
- `TreeCapLog` — debug logging
- `TreeCapSneak` — sneak gate logic
- `PendingReplant` — stump record (location, log type, ground, sapling)
- `ChainLimiter` — tool durability budget cap
- `BreakProtection` — synthetic break/place events for protection plugins
### Updated classes
- `TreeCapitatorListener` — full tree-cap handler (sneak, cooldown, sync/async, deferred replant, debug)
- `BulkBreakExecutor` — async waves, per-block damage, deferred replant
- `TreeCapitatorConfig` — new settings, `block-damages` parsing, load-time config log
- `BreakSession` — cooldown and shift tracking
- `BulkDropAccumulator` — sapling consume/count for replant
- `ToolHelper` — durability budgeting and multi-point damage with Unbreaking
- `AdjacentFlooder` — Folia-safe reads, trunk-priority flood fill
- `DropHelper` — per-block drop spawning
- `TreeBlockGroup` — `matchesBlock()` for group checks
### Removed
- `ReplantHelper` — replaced by `TreeReplant` (old immediate per-block replant)
### Not included (Normal Essentials only)
- Drill axe coordination
- Veinminer
- Auto-smelt / fortune integrations

## After Updating
1. Replace the plugin JAR and **restart** the server (code changes require a restart; `/tc reload` only reloads config/messages).
2. On load you should see:  
   `[TreeCap] config <path> must-sneak=... debug=... async-start=... replant=...`
3. Set `debug: true` in `plugins/NormalTreeCapitator/config.yml` to troubleshoot — look for `[TreeCap] evaluate ...` and `START ...` in `latest.log`.
4. **Do not run NormalTreeCapitator and Normal Essentials tree cap on the same server** — they will conflict.
