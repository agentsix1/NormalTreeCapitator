# NormalTreeCapitator 1.0.6

Changelog since **1.0.5**.

---

## Highlights

- **Update feed** — switched from Pastebin to GitHub [`version.txt`](https://raw.githubusercontent.com/agentsix1/NormalTreeCapitator/main/version.txt) (`version|download url`); current line is `v1.0.6|https://modrinth.com/plugin/normal-tree-capitator/versions`
- **`/tc cancel`** / **`/tc stop`** — halt an in-progress tree break, instantly release collected merged drops at the stump, and stop further axe damage
- Permission **`normaltreecapitator.cancel`** (default `true`, included in `normaltreecapitator.user`)
- Works for both sync and async (waved) break paths

---

## Update checks

The plugin reads the latest release from [GitHub version.txt](https://raw.githubusercontent.com/agentsix1/NormalTreeCapitator/main/version.txt) instead of Pastebin.

| When | What happens |
|------|----------------|
| **Every 30 minutes** | Re-fetches `version.txt`. If a newer version appears (or the feed changed), console + online ops / `normaltreecapitator.admin` are notified |
| **Plugin enable** | Immediate check; notify console + online staff if outdated |
| **Player join** | Fresh check for that player if they are op or have `normaltreecapitator.admin` |
| **Every 3 hours** | Reminder to console + online staff while still outdated |
| **`/tc version`** | Fresh check for staff/ops who run it (clickable link if outdated) |

## Commands (1.0.6)

### Default user pack (`normaltreecapitator.user`)

| Command / feature | Permission | Default | Effect |
|-------------------|------------|---------|--------|
| (breaking) | `normaltreecapitator.use` | `true` | Tree cap when breaking blocks |
| `/tc` | `normaltreecapitator.status` | `true` | Your toggle state |
| `/tc status` | `normaltreecapitator.progress` | `true` | Live break progress (`done/total`, `%`, rough ETA) |
| `/tc cancel` / `/tc stop` | `normaltreecapitator.cancel` | `true` | Stop the current break; flush collected drops; no more axe damage |
| `/tc help` | `normaltreecapitator.help` | `true` | Only the subcommands you can use |
| `/tc toggle` | `normaltreecapitator.toggle` | `true` | Toggle tree capitator for yourself |

### Other commands

Unchanged from **1.0.5** (`/tc <player>`, toggle others, reload, version, language).

---

## Behavior notes

- With **`merge-item-drops: true`** (default), cancel drops whatever has been collected so far at the origin block.
- With **`merge-item-drops: false`**, per-block drops already spawned in the world; cancel only stops further breaks and axe damage.
- Cancel skips unfinished replant for the interrupted chain.
- If nothing is breaking, you get an idle message instead of an error.

---

## Upgrade notes

1. Drop `NormalTreeCapitator-1.0.6.jar` into `plugins/` and **restart** (or reload plugins carefully).
2. Run `/tc reload` so language files pick up `help-cancel`, `chain-cancelled`, and `chain-cancel-idle`.
3. Update checks no longer use Pastebin — ensure repo root [`version.txt`](https://github.com/agentsix1/NormalTreeCapitator/blob/main/version.txt) is on `main` as:

```text
v1.0.6|https://modrinth.com/plugin/normal-tree-capitator/versions
```
